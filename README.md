🤖 Assistente FP — Inteligência Artificial para Windows

Assistente pessoal desenvolvido em Python, com inteligência artificial executada localmente, reconhecimento de voz em português e automação de tarefas no Windows.

O projeto tem como objetivo facilitar atividades cotidianas, permitindo que o usuário interaja com o computador por comandos de texto ou voz, utilizando uma interface gráfica independente.

🚀 Funcionalidades

🎙️ Reconhecimento de comandos de voz em português.

🧠 Integração com modelos de IA locais utilizando Ollama.

🖥️ Abertura de aplicativos instalados no Windows.

📂 Pesquisa e abertura de arquivos pessoais.

📁 Criação de pastas com confirmação do usuário.

💬 Interface gráfica para interação por texto.

🔒 Processamento local, sem necessidade de API paga.

📥 Instalação

Pré-requisitos: Windows, Python e Ollama instalados.

Baixe o projeto utilizando a opção Code → Download ZIP no GitHub.

Extraia os arquivos em uma pasta.

Execute Instalar modelo melhor.bat para baixar o modelo Qwen3 4B Instruct.

Execute Instalar voz.bat para instalar as dependências do reconhecimento de voz.

Execute Abrir Assistente.bat para iniciar a interface.

Na primeira utilização do microfone, o sistema fará o download do modelo de transcrição Whisper.

🔐 Segurança e limitações

O assistente utiliza ações previamente definidas para controlar o Windows e solicita confirmação em operações específicas.

A busca de arquivos é limitada às pastas pessoais configuradas. Alguns aplicativos podem não ser encontrados quando não possuem atalhos no Menu Iniciar.

O reconhecimento de voz é ativado pelo usuário e não permanece ouvindo continuamente. A versão atual recebe comandos por voz, mas não responde falando.
